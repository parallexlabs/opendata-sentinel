# OpenData Sentinel

OpenData Sentinel is an engineering demonstration of configured dataset checks and inspectable reports. Local results and capabilities are externally unverified until independently reproduced; municipal actionability remains unreviewed. Dataset sources and licences are in the [sample inventory](sample-provenance.md) and [data inventory](DATA_LICENCES.md).

See [Quickstart](quickstart.md) to run your first check.

Start with the [required-field workflow](case-study.md), [release verification](release-verification.md) and [current results](results.md). Earlier milestones remain in the [audit-history appendix](AUDIT_HISTORY.md).
